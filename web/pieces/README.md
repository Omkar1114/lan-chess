# Piece sets

Each folder is one piece set: twelve SVG files named `<colour><piece>.svg`
(`wK`, `wQ`, `wR`, `wB`, `wN`, `wP`, `bK`, ...). The server lists the folders
automatically, so adding a set is just adding a folder.

Authors and licences of the bundled sets are listed in
[`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md). Only add sets whose
licence allows redistribution, and record them there.
